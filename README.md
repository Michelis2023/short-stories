## Ενημερώσεις και επικοινωνία

Στην αρχική σελίδα θα βρείτε συνδέσμους προς τα κοινωνικά δίκτυα του συγγραφέα και φόρμα για να ζητήσετε ενημερώσεις για νέα διηγήματα.

Η φόρμα χρησιμοποιεί την υπηρεσία Formspree. Το μήνυμα επιτυχίας επιβεβαιώνει ότι το αίτημά σας στάλθηκε, όχι ότι εγγραφήκατε αυτόματα σε λίστα ενημερώσεων.

## Σχετικά με το αποθετήριο

Το αποθετήριο περιέχει τα αρχεία της ιστοσελίδας της συλλογής. Για να διαβάσετε τα διηγήματα, ακολουθήστε τους συνδέσμους στην αρχή της σελίδας.

Η αρχική σελίδα χρησιμοποιεί HTML και CSS, με μικρό τμήμα JavaScript για την αποστολή της φόρμας. Η αρχική σελίδα χρησιμοποιεί τη γραμματοσειρά Georgia. Αν δεν είναι διαθέσιμη, χρησιμοποιείται η Times New Roman ή άλλη γραμματοσειρά με πατούρες. Τα εικονίδια προέρχονται από το Font Awesome μέσω εξωτερικής υπηρεσίας.

Η δημοσίευση γίνεται μέσω GitHub Pages. Το CSS της αρχικής σελίδας περιλαμβάνει κανόνες προσαρμογής για μικρές οθόνες. Η εμφάνιση δεν έχει ακόμη ελεγχθεί σε όλες τις συσκευές και τα προγράμματα περιήγησης.

Δεν απαιτείται εγκατάσταση πακέτων ή διαδικασία μεταγλώττισης για την προβολή των στατικών αρχείων. Οι εξωτερικές υπηρεσίες, όπως η φόρμα και τα εικονίδια, χρειάζονται σύνδεση στο διαδίκτυο.
