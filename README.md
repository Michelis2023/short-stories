## Ενημερώσεις και επικοινωνία

Στην αρχική σελίδα θα βρείτε συνδέσμους προς τα κοινωνικά δίκτυα του συγγραφέα και φόρμα αιτήματος για ενημερώσεις σχετικά με νέες δημοσιεύσεις.

Η φόρμα χρησιμοποιεί την υπηρεσία Formspree. Η επιτυχής αποστολή αιτήματος δεν αποτελεί από μόνη της επιβεβαίωση ενεργοποίησης αυτόματης συνδρομής.

## Σχετικά με το αποθετήριο

Το αποθετήριο περιέχει τα αρχεία της ιστοσελίδας της συλλογής. Για ανάγνωση, χρησιμοποιήστε τους συνδέσμους που βρίσκονται στην αρχή αυτού του README.

Η αρχική σελίδα χρησιμοποιεί HTML και CSS, με μικρό τμήμα JavaScript για την αποστολή της φόρμας. Η γραμματοσειρά της ορίζεται ως Georgia, με εναλλακτικές Times New Roman και serif. Τα εικονίδια προέρχονται από το Font Awesome μέσω εξωτερικής υπηρεσίας.

Η δημοσίευση γίνεται μέσω GitHub Pages. Το CSS της αρχικής σελίδας περιλαμβάνει κανόνες προσαρμογής για μικρές οθόνες. Αυτό δεν αποτελεί πιστοποίηση δοκιμής σε κάθε συσκευή ή πρόγραμμα περιήγησης.

Δεν απαιτείται εγκατάσταση πακέτων ή διαδικασία μεταγλώττισης για την προβολή των στατικών αρχείων. Οι εξωτερικές υπηρεσίες, όπως η φόρμα και τα εικονίδια, χρειάζονται σύνδεση στο διαδίκτυο.
